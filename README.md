# QLSTM vs Classical Baselines — Reproducible Benchmark on GARCH-Simulated Data

This repository contains the complete, reproducible code and data for the paper:

> **Benchmarking a Quantum Long Short-Term Memory Network against Five Modern
> Classical Baselines for Volatility-Clustered Time Series Forecasting on
> GARCH-Simulated Asset Classes**

Everything needed to reproduce every table and figure in the manuscript is here.
The full benchmark runs on a **single CPU core in about twelve minutes** — no GPU,
no internet, no quantum hardware required.

---

## What this study does

Six forecasting architectures are compared at a matched parameter budget
(< 350 trainable parameters) on four synthetic asset classes generated by
calibrated GARCH(1,1) processes:

| Asset class  | Annualised σ | GARCH (ω, α, β)         |
| ------------ | ------------ | ----------------------- |
| FX           | 0.056        | (2.0e-7, 0.05, 0.93)    |
| EQUITY_MID   | 0.183        | (2.0e-6, 0.08, 0.90)    |
| EQUITY_HIGH  | 0.318        | (1.5e-5, 0.10, 0.85)    |
| CRYPTO       | 0.844        | (8.0e-5, 0.14, 0.82)    |

**Models:** LSTM, BiLSTM, PatchTST (compact), N-BEATS (compact),
iTransformer (compact), and a 4-qubit QLSTM with 2 variational blocks.

**Evaluation:** RMSE, directional accuracy, Wilcoxon signed-rank tests,
3-fold walk-forward validation, transaction-cost-aware trading utility,
depolarising-noise robustness, and a VQC depth ablation.

---

## Key findings

- Plain **LSTM achieves the lowest RMSE on every asset class** at this small-model budget.
- **QLSTM has the lowest seed-to-seed variance** across all four classes.
- **QLSTM has the highest directional accuracy on the CRYPTO class** (57.3%).
- The **VQC depth ablation shows monotonic worsening with depth**, consistent
  with barren-plateau onset at 4-qubit width.
- A **non-monotonic noise effect** on the CRYPTO class is interpreted as
  implicit stochastic regularisation (not a hardware advantage).

## Reproduce everything

```bash
# 1. Install (numpy + scipy + matplotlib is all that's strictly needed)
pip install -r requirements.txt

# 2. Run the four studies (each caches its JSON in results/raw/)
python -m src.chunked_runner main
python -m src.chunked_runner noise
python -m src.chunked_runner depth
python -m src.wf_chunk EQUITY_MID
python -m src.wf_chunk EQUITY_HIGH
python -m src.wf_chunk FX
python -m src.wf_chunk CRYPTO

# 3. Aggregate into the 8 tables + 4 figures
python -m src.chunked_runner aggregate
```

Outputs land in `results/tables/` and `results/figures/`.

### Quick sanity check (≈ 60 seconds)

```bash
python -m src.authentic_minimal
```

## Data provenance

**All data in this repository is synthetic.** It is generated by the
GARCH(1,1) process in `src/authentic_smoke_test.py` (function `garch11` and
`make_dataset`) using the seeds in `seeds.txt`. No real market data is used.
The CSV files in `data/` are provided for convenience so that the exact series
can be inspected without running the generator; they are bit-reproducible from
the code and seeds.

---

## Optional: running on real Yahoo Finance data

The repository also includes `src/data_loader.py`, a fetcher for real Yahoo
Finance data (NVDA, AAPL, JPM, EURUSD=X, GBPUSD=X, BTC-USD, ETH-USD), patched
for the 2025+ Yahoo API via `curl_cffi`. To extend this study to empirical
data, install `yfinance` and `curl-cffi`, run `python -m src.data_loader`, then
adapt the asset list in `full_authentic_benchmark.py`. Note that PennyLane-based
QLSTM training on the full empirical dataset is computationally heavy; the
NumPy state-vector path in this repository is what keeps the benchmark to
twelve minutes.
